## 🚀 Step-by-Step Guide

Follow the steps below in order.

### 1. 🎮 Open your Roblox game

Open the Roblox experience that you own or are authorized to export.

### 2. 🖱️ Open Developer Tools

Right-click anywhere on the page.

Choose:

**Inspect**

Then open the:

**Network** tab.

### 3. 🔄 Refresh the page

Reload the page by pressing:

```text
Ctrl + R
```

Wait a few seconds for the Network requests to load.

### 4. 🔎 Find the game request

Look through the Network requests for the one containing the game name or other information related to your authorized project.

> 💡 The relevant request is often near the top, but its position can vary.

### 5. 📋 Copy the request

Right-click the relevant request and select:

**Copy → Copy as PowerShell**

This copies the request information to your clipboard.

### 6. 🌐 Open RobloTools

Go to:

**[RobloTools Game Downloader](https://roblotools.com/game-downloader/unc)**

Paste the copied request into the input field and click the button provided by the website.

Then follow the instructions shown on the website.

## ❓ Troubleshooting

<details>
<summary><strong>🔎 I can't find the Network tab</strong></summary>

Open Developer Tools by pressing:

```text
F12
```

Then select **Network**.

</details>

<details>
<summary><strong>🔄 I can't find the request</strong></summary>

Refresh the page and wait until the Network list is populated.

You can also use the search or filter field in Developer Tools to make finding the request easier.

</details>

<details>
<summary><strong>📋 "Copy as PowerShell" is not available</strong></summary>

Make sure you are right-clicking the actual network request in the **Network** panel.

</details>
